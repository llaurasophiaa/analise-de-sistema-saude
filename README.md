# analise-de-sistema-saude
# sistema de agendamento de consultas

## 1. visao geral
Este documento especifica os requisitos funcionais do modulo de agendamento

## 2. Requisitos Fucionais (RF)
- [ ] RF01: o paciente deve conseguir visualizar os horários disponíveis de cada medico
- [ ] RF02: o sistema deve permitir o agendamento de consultas com confirmação por e-mail
- [ ] RF03: o medico deve visualizar sua agenda diaria e semanal.

## 3. Requisitos Nao Funcionais (RNF)
- RNF01 (Desempenho) : O tempo de resposta para busca de horarios nao deve exceder 2 segundos
- RNF02 (Segurança) : Dados sensiveis de saude devem estar em conformidade com a LGPD.
